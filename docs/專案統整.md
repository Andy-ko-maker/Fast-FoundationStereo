# Fast-FoundationStereo 專案統整（繁體中文）

## 這個專案在做什麼
輸入一對左右相機影像，輸出每個像素的**視差(disparity)**，再用 `深度 = 焦距 × 基線 ÷ 視差` 換成深度與點雲。
特色是「零樣本、即時」：比 FoundationStereo 快 10 倍以上，準確度接近。

## 三個加速手法（論文）
1. **知識蒸餾**：把混合骨幹壓縮成單一高效學生網路。
2. **分塊神經架構搜尋(NAS)**：在延遲預算下自動找最佳代價體聚合結構。
3. **結構化剪枝**：精簡迭代細修(GRU)模組。

## 推論流程
```
左右圖 → 特徵骨幹(多尺度) → 建代價體(GWC + concat)
      → hourglass 3D 聚合 → 分類器 → 初始視差
      → GRU 迭代細修(1/4 解析度，查詢幾何編碼體)
      → 上採樣回原解析度 → 視差圖 → 深度/點雲
```

## 常用參數
- `--valid_iters`：GRU 迭代次數，越少越快、越多越準（預設 8）。
- `--max_disp`：最大視差搜尋範圍（預設 192）。
- `--scale`：輸入縮放比例，縮小可加速。
- `--hiera`：開啟由粗到細的兩階段推論，適合高解析度。
- `--remove_invisible`：移除只在左圖可見的像素。

## 快速開始
```bash
python scripts/run_demo.py --model_dir weights/23-36-37/model_best_bp2_serialize.pth \
  --left_file demo_data/left.png --right_file demo_data/right.png --out_dir ./out
```
